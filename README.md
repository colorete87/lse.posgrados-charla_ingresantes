# Charlas de Posgrados en IA — @lse.posgrados

Este repositorio contiene las presentaciones interactivas basadas en [Reveal.js](https://revealjs.com/) para las charlas informativas e ingresantes de las carreras de posgrado del **Laboratorio de Sistemas Embebidos (LSE)** de la **Facultad de Ingeniería, Universidad de Buenos Aires (FIUBA)**.

---

## 📊 Presentaciones Disponibles

### 1. 📢 [Charla Informativa — Carreras de Inteligencia Artificial](charla_informativa.html)
* **Archivo local:** [`charla_informativa.html`](charla_informativa.html)
* **Ver online (GitHub Pages):** [https://colorete87.github.io/lse.posgrados-charlas/charla_informativa.html](https://colorete87.github.io/lse.posgrados-charlas/charla_informativa.html)
* **Descripción:** Presentación de la oferta de posgrados en IA: Diplomatura en IA Aplicada (DIIAA), Diplomaturas Específicas (DVpC, DPLN, DRLAE), Carrera de Especialización en IA (CEIA), Maestría en IA (MIA) y Maestrías Combinadas (MIAE, MCB, MIoT).

### 2. 🎓 [Charla para Ingresantes](charla_ingresantes.html)
* **Archivo local:** [`charla_ingresantes.html`](charla_ingresantes.html)
* **Ver online (GitHub Pages):** [https://colorete87.github.io/lse.posgrados-charlas/charla_ingresantes.html](https://colorete87.github.io/lse.posgrados-charlas/charla_ingresantes.html)
* **Descripción:** Orientación e información inicial para los nuevos estudiantes admitidos en la CEIA.

## 💻 Cómo visualizar localmente

Puedes clonar el repositorio e ingresar directamente desde tu navegador:

```bash
git clone https://github.com/colorete87/lse.posgrados-charlas.git
cd lse.posgrados-charlas
```

Abrir `charla_informativa.html` o `charla_ingresantes.html` haciendo doble clic en el archivo o sirviéndolo mediante un servidor local HTTP:

```bash
python -m http.server 8000
```
Luego navegar a `http://localhost:8000/charla_informativa.html`.
